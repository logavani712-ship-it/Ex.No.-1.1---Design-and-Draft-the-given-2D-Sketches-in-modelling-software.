## AIM

To sketch the given drawing with dimensions using fusion 360 tool.

## REQUIREMENTS

  1. Autodesk fusion 360
  2. Windows 10
  3. 16 GB of RAM (integrated graphics recommend 2 GB or more)
  4. 2.5 Mbps or faster download; 500 Kbps or faster upload 
  
## PROCEDURE
1. Launch Autodesk Fusion 360 and open a new design. Choose Create Sketch from the toolbar and select the XY Plane. Check that the required sketch settings and units are selected.


2. From the Sketch toolbar, select Create → Circle → Center Diameter Circle. Click the origin as the centre and draw the outer circle with a diameter of Ø32 mm. From the same centre, create another concentric circle of Ø20 mm.

![image](https://user-images.githubusercontent.com/113594316/198206497-ca83d495-119b-45cd-b43d-8ca3ea7e9544.png)

3. Draw the required circles at the bottom-left, bottom-right and bottom-centre positions according to the given drawing. Set their required diameters using the Sketch Dimension option.


4. Apply Horizontal/Vertical and Coincident constraints to position the circles correctly. This helps to keep the features aligned with the origin and with each other.


5. Select the Line tool and draw the necessary construction and reference lines. Use the given dimensions such as 47 mm and 50 mm to locate the required features accurately.

![image](https://user-images.githubusercontent.com/113594316/198206562-68463016-3f32-4a87-aa5b-7a17dd023b31.png)
6. Use the Arc tool to form the curved sections between the upper circular portion and the lower features. Apply Coincident and Tangent constraints so that the curves join the connected parts smoothly.


7. Complete the outer shape by adding the required lines, arcs and circles based on the reference drawing. Apply the given overall dimension of 65 mm to obtain the correct height and position.


8. Create the inner circular and curved portions using the Circle and Arc tools. Apply the specified dimensions Ø40 mm, Ø20 mm, Ø14 mm and Ø10 mm using the Sketch Dimension tool.


9. Select the Trim tool and remove the unwanted portions of circles and arcs. Trim only the extra parts while keeping the required profile and connecting curves.


![image](https://user-images.githubusercontent.com/113594316/198206621-6348e8a3-4bbd-4a1f-96d3-db16fbf933d9.png)

10. Add the remaining internal features shown in the drawing. Position the circles, arcs and curves properly by referring to the construction lines and given dimensions.


11. Apply the required geometric constraints such as Coincident, Horizontal/Vertical and Tangent. Make sure that the connected curves join correctly without gaps or overlaps.


12. Use the Trim command wherever necessary to remove any extra circles, arcs, lines or construction geometry. Check that only the required sketch profile remains.


13. Compare the completed sketch with the given reference drawing. Check all diameters, distances, heights and positions and correct any mistakes found.


14. Inspect the complete sketch carefully and make sure all circles and curves are properly connected. Confirm that the required constraints are applied and that there are no unwanted or overlapping elements.


15. After checking the sketch, select Finish Sketch to leave the sketching environment. Save the completed Fusion 360 design with the required file name.

![image](https://user-images.githubusercontent.com/113594316/198206639-31c4bdb5-b13e-4106-bcf5-125c294aa03e.png)

16. Finally, switch to the Drawing workspace and prepare the sketch in ISO standard. Thus, the required engineering sketch is successfully created using Autodesk Fusion 360.
